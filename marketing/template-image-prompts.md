# برومتات توليد صور القوالب (٢٢ قالب)

برومت جاهز لكل قالب، تنسخه بأي أداة توليد صور (Midjourney / DALL·E / Leonardo / Firefly…) وتطلع صورة تمثّل هوية القالب لبوستات إنستغرام ("اختار قالبك").

**طريقة الاستخدام:**
1. انسخ برومت القالب.
2. الصق **مقطع الستايل الموحّد** بآخره (تحت) — بيخلّي كل الصور تطلع كسلسلة متناسقة على الشبكة.
3. المقاس المقترح **٤:٥ عمودي** (أنسب لإنستغرام). بـMidjourney زيد `--ar 4:5`.

> **بديل أسرع:** عندي القوالب مرندرة فعلاً — أقدر آخذلك لقطة حقيقية لكل قالب بدل الصور المولّدة لو بتفضّل. بس هدول البرومتات لو بدك صور مود/إعلانية أنيقة.

---

## 🎨 مقطع الستايل الموحّد (الصقه بآخر كل برومت)

```
— premium minimal hero illustration for a personal-website theme,
generous negative space for a headline, soft cinematic depth,
no text, no watermark, no UI elements, high detail, 4:5 vertical --ar 4:5
```
