## Purpose

The student picks a **feeling**, not a layout number. All 28 templates are visible and previewable with the student's own data; the lock only appears at publish.

## Layout Overrides

- Grid: 1 col (375) · 2 (768) · 3 (1024) · 4 (1440). Gap 24px. Cards keep a fixed `aspect-ratio: 3 / 4` so the grid never shifts while previews load.
- **Card anatomy** (top → bottom): live mini-preview (the template's hero card rendered with the current draft or, when there is no draft, the no-experience fixture, scaled to fit) → mood name (display face, 1.25rem) → one-line feeling («برد نظيف وواضح») → chips: `فاتح/داكن` lean, and for paid templates «ضمن الخطة المدفوعة» (muted chip, not a padlock over the preview).
- Filters (chip row, `role="group"`): الكل · فاتح · داكن · هادئ · جريء · مجاني. Filtering re-orders with FLIP (400ms) and never hides the currently selected template.
- Selected card: 2px `--color-accent` border + check icon with accessible label «مختار».
- **Preview action:** «جرّب بمعلوماتك» opens the full template with the draft in a full-screen sheet at the visitor's real viewport (not a scaled thumbnail), with language/theme toggles inside the sheet.

## Color Overrides

- Each card's mini-preview carries its own template background; the gallery page background itself is the Master light/dark mesh at reduced saturation (`opacity: .6` on orbs) so 28 different backgrounds don't fight.

## Motion Overrides (motion 5/10)

- Card entrance: Stagger List subtle (`y 8`, 300ms, stagger 0.03) — **not** `back.out` (the generator's suggestion overshoots; rejected for a card grid the student scans).
- Hover: `y −2px`, border brightens (200ms). The mini-preview's orbs are **static** in the grid (only the opened sheet animates) to keep 28 cards cheap.
- Filter reflow: GSAP Flip 400ms `power2.inOut`, opacity for entering/leaving cards.
- Reduced motion: instant reflow, no entrance.

## Accessibility

- Cards are `<button>`s (select) with a secondary link (preview). Roving tabindex across the grid; arrow keys move in reading direction (RTL-aware).
- Lock information is text, never icon-only.
