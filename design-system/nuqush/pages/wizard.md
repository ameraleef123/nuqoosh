# Wizard Page Overrides — `/new` and `/edit/{token}`

> **PROJECT:** Nuqush
> **Generated by skill:** 2026-09-08 (query: "multi-step form wizard live preview autosave calm focused", motion 4/10)
> **Reconciled against brief:** 2026-09-08

> ⚠️ Rules in this file **override** `design-system/nuqush/MASTER.md`. Only deviations are documented here.

---

## Purpose

Six steps, ~10 minutes, colloquial Jordanian-friendly Arabic, no account. The student must never be stuck and must never feel that an empty experience section is a deficiency.

## Layout Overrides

- **≥1024px:** two columns. Form column `7/12` (max 640px reading width), preview column `5/12`, preview is `position: sticky; inset-block-start: 24px`. Preview shows the real `TemplateRenderer` at a scaled-down 375px viewport (CSS `zoom`/`transform: scale`), with the template switcher above it.
- **<1024px:** single column. Preview lives in a bottom sheet opened by a floating «معاينة» button (44×44 min target, glass pill, `inset-inline-end: 16px; inset-block-end: 16px`). Sheet uses the `.glass-strong` surface.
- **Step header:** step counter «الخطوة ٣ من ٦», step title, one-sentence human intro. Progress = the completion meter ring (not a step bar); the step list itself is a horizontal scrollable pill row that is keyboard-navigable (`role="tablist"`).
- **Footer bar (sticky, bottom):** «رجوع» (ghost) · autosave state · «التالي» (primary). On the last step «التالي» becomes «انشر». The bar is `.glass` and never covers form content (form has `padding-block-end: 96px`).

## Density

- `--density` 4/10 → spacing scale stays Master (`16–64px`), but inputs are `min-height: 48px`, gap between fields `24px`, gap between field groups `40px`.

## Typography Overrides

- Field labels: body face, 600, `1rem`. Hints: body face, 400, `0.9375rem`, colour `--color-muted-foreground` (measured 8.70:1 light / 10.64:1 dark). **Hints are never red, never orange, never bold.**
- Step titles: display face 700, `clamp(1.5rem, 2.5vw, 2rem)`, `line-height: 1.3`.

## Color Overrides

- The generator suggested step colours (red/orange/green). **Rejected**: the wizard uses **one** accent (`--color-accent`). Colour never encodes "problem" here.
- `--color-destructive` is used only for the delete-item confirmation. Nothing about validation is red.
- Input surface: `.glass-subtle` in light, `.glass` in dark; focus = `2px` ring `--color-ring` + border to `--color-accent`.

## Component Overrides

- **Hint, not validation.** Each field renders `<p id="…-hint">` linked via `aria-describedby`. No `aria-invalid`, no error state, no blocking. Length hints count up in the same muted colour («٤٧ / ١٢٠»).
- **«التالي» always enabled.** There is no disabled state for the next button. Skipping is a first-class action, not a bypass.
- **Step 5 (الخبرة)** header carries the chip «اختياري — بتنتخطّى» and a one-line reassurance: «ما عندك خبرة؟ عادي، أغلب الطلاب هيك. تخطّى وخلّي مشاريعك تحكي.»
- **Completion meter** (ring, top of the form column): counts fields across steps 1–4 and 6; step 5 contributes nothing. The «نشاطات» axis is satisfied by any one of: experience, volunteering, activities. Reaches 100% with experience empty. At 100%: one 400ms pulse + the label changes to «جاهز للنشر». No confetti.
- **Autosave indicator** (footer bar, `aria-live="polite"`): «جارٍ الحفظ…» → «محفوظ تلقائيًا» with a subtle check icon. Debounce 600ms on keystroke, immediate on blur / step change / tab hide (`visibilitychange`). Draft is also mirrored to `localStorage` keyed by draft id so a refresh restores unsent keystrokes.
- **Repeaters** (projects, volunteering, links): add button is a dashed `.glass-subtle` card «+ أضف مشروع»; items are `.glass` cards with drag handle (keyboard: alt+arrow), edit inline.
- **Bilingual fields:** Arabic input is the field. English is an expandable «أضف بالإنجليزي (اختياري)» row under the field, LTR input with `dir="ltr"`. Never a global "translate everything" switch.
- **Template switcher** (above preview): horizontal strip of mood chips; selecting runs the FLIP crossfade on the preview hero (600ms expo.inOut). Locked templates are selectable and previewable; the lock chip reads «ضمن الخطة المدفوعة» and only intervenes at publish.

## Motion Overrides (motion 4/10 — calmer than Master)

| Moment | Spec |
|--------|------|
| Step change | Exit 200ms opacity→0 + x ∓8px, enter 400ms opacity + x ±24px→0, `expo.out`. Direction follows `dir`: in RTL the next step enters **from the left**. |
| Field focus | CSS only: border-color + ring, 150ms. |
| Repeater add/remove | Item height is **not** animated; new item fades in 250ms, removed item fades out 150ms then unmounts. |
| Meter | count-up 600ms `power2.out` on a proxy number; ring `stroke-dashoffset` transition 600ms. |
| Preview updates | Text updates are instant (no animation on typing). Only template switch animates. |
| Reduced motion | No step slide (instant swap), no count-up (jump), no pulse. |

## Copy Tone (Arabic, colloquial, warm)

- Step titles: «من أنت؟» · «شو بتدرس؟» · «مشاريعك» · «تطوّعك ونشاطاتك» · «خبرتك (اختياري)» · «روابطك وتواصلك»
- Never: «يرجى إدخال», «حقل مطلوب», «خطأ».
- Always: short, second person, no exclamation marks except the 100% moment.

## Accessibility

- Every input has a visible `<label for>`; hint is `aria-describedby`.
- Focus order equals visual order; step pills are arrow-key navigable; the sticky footer never obscures the focused field (scroll-margin-block-end: 112px on inputs).
- Touch targets ≥44px; the mobile preview button ≥48px.
