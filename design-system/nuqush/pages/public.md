## Purpose

The page a recruiter opens on a phone on a weak network. It must be readable before any script loads, proud-making within two seconds, and never show an empty section.

## Layout Overrides

- **Max width:** 720px reading column for content sections; hero may bleed to 960px. Background layers are full-bleed.
- **Layer stack (max 3 glass layers):** `bg-mesh` (fixed, `pointer-events:none`) → `orbs` (2–3 elements, transform-only loops) → `.glass` section cards → content.
- **Section anatomy:** one glass card per section, `padding: 24px` (375) / `32px` (≥768). Section heading is display face 700 at `1.5rem`, with a 2px accent hairline `inline-size: 32px` under it (`margin-inline-start: 0`).
- **Hero card:** avatar (optional, 96px, `next/image`, blur placeholder), name (display face, `clamp(2.25rem, 6vw, 3.5rem)`, `line-height: 1.3`), one-line tagline (body face, `1.125rem`), a row of small pills: university · major · year · GPA (each pill only if present).
- **Default section order** is the template's variant (A/B/C in `templates.md`). The renderer receives an ordered list and **filters out any section whose data is empty before rendering** — no heading, no card, no gap, no "add" nudge.
- **Footer:** language toggle · theme toggle · «الإبلاغ عن هذه الصفحة» (always) · «مبني بنُقوش» badge (free tier only, small, links to `/`).

## Content rules

- Course projects render a badge «مشروع مساق» (amber chip: `#F5B942` bg with ink text, 10.12:1). Personal projects get «مشروع شخصي». Badges are text, not colour-only.
- Volunteering heading is «تطوّع وقيادة» not «تطوّع»; each item shows the role first («مدرّب — نادي البرمجة») and impact line («درّب ٢٥ طالبًا»).
- Experience heading is «خبرة عملية» and appears only when ≥1 job.
- Phone: rendered as `tel:` link only when the field exists. Absent → not in DOM.
- Numerals: Arabic-Indic in `ar` (٣٫٤، ٢٠٢٦), Western in `en`. Formatting via `Intl.NumberFormat` with `numberingSystem` (`arab` / `latn`), never string replacement of the source data.
- Language toggle switches: `dir`, `lang`, font stacks, numerals, mirrored icons, and every field's `ar`/`en` value, falling back to `ar` per field.

## Typography Overrides

- Body `1.0625rem` / `line-height: 1.75` in Arabic, `1.6` in English. Minimum on any text: `0.875rem`.
- Name is the only element that uses SplitText (headline-length rule).

## Color Overrides

- Text on glass must be ≥4.5:1 in **both** themes. Light glass over pastel orbs measured ≥10.1:1 worst case; dark glass must use the ink-tinted `--glass-bg` (see Master) so that the worst case (bright orb behind panel) stays ≥5:1. **If a template fails, darken the panel; never lighten the text.**
- Links inside body text are underlined (not colour-only), colour `--color-accent`.

## Motion Overrides (motion 7/10)

| # | Signature | Trigger | Spec |
|---|-----------|---------|------|
| 1 | Hero name | load | SplitText chars, `opacity 0→1`, `y 20→0`, 600ms, `expo.out`, stagger 0.015. Card: `y 16→0` + opacity, 500ms, delay 0.1s. Orbs: CSS `@keyframes` drift 24–36s, `transform` only, `animation-play-state: paused` when tab hidden or orb offscreen (IntersectionObserver). |
| 2 | Section reveal | scroll enter | `opacity 0→1`, `y 12→0`, 350ms, `power1.out`, `start: 'top 90%'`, `toggleActions: 'play none none reverse'`. Children stagger 0.03. |
| 3 | Glass hover (project cards, links) | hover | `y −2px` 200ms `power1.out`; border alpha and blur +2px via CSS transition 200ms (hover only, never on scroll). |
| — | Page transitions | — | Not applicable: the public page is a single route. Language/theme toggles crossfade content 250ms. |
| — | Template switch | — | Not applicable on the public page (builder-only). |
| — | Completion | — | Not applicable. |

- **No-JS / pre-hydration:** content is server-rendered visible. The initial hidden state for reveals is applied by CSS only when `html.js` **and** `(prefers-reduced-motion: no-preference)` match; GSAP then animates to the final state. JS off → everything visible. Reduced motion → everything visible, no tweens created (`gsap.matchMedia`).
- **Mobile (<768):** no parallax, orbs reduced to 2, blur capped at 12px for GPU cost.

## Performance budget (public route)

| Metric | Budget |
|--------|--------|
| LCP (throttled 4G, mid phone) | < 2.5s |
| Client JS (gz) | ≤ 120 KB total; motion layer ≤ 40 KB of that |
| Fonts | 2 families max per template, Arabic subset + Latin subset, `font-display: swap`, preloaded via `next/font` |
| Images | `next/image`, AVIF/WebP, blur placeholder, avatar ≤ 40 KB |
| Rendering | SSG via `generateStaticParams` + ISR (`revalidate`), `revalidateTag(handle, 'max')` on publish; page is served from the cache when origin is slow |
| CLS | < 0.1 (reserve avatar and badge space) |

## Measured budget finding (Phase 1) — GSAP cannot ship on the public page

Measured on the Phase 1 build, gzipped:

| Item | Size (gz) |
|------|-----------|
| Framework floor for **any** route (React 19 + Next 15 App Router shared chunks) | 103 KB |
| GSAP core | 27.6 KB |
| ScrollTrigger | 17.5 KB |
| Flip | 9.5 KB |

The floor plus GSAP core and ScrollTrigger is ~148 KB before a single line of page code, against a
120 KB budget. The budget is not reachable with GSAP on this route.

**Resolution:** split the motion layer by route, not by preference.

- **Public page `/{handle}`** — motion signatures 1, 2 and 3 only, implemented as CSS keyframes and
  transitions plus one `IntersectionObserver` (~2 KB). Signature 2's contract is unchanged: opacity
  and a 12px translate, 350ms, played once on enter and reversed on leave. Signatures 4, 5 and 6 do
  not occur on this route.
- **Builder routes (`/new`, `/edit/{token}`, `/gallery`)** — GSAP with ScrollTrigger and Flip. These
  are authenticated-feeling working surfaces on the student's own connection, not the recruiter's
  first impression, so the 120 KB budget does not apply.

This keeps the public page at roughly 105 KB gz and preserves "content-first render: the page is
readable before any animation library loads", which a 45 KB motion library on the critical path
would contradict anyway. The single-library rule still holds within each context.

## Safety

- «الإبلاغ عن هذه الصفحة» in the footer opens a minimal sheet (reason select + optional note), posts to `/api/reports`, shows «وصلنا بلاغك. شكرًا.».
- Hidden pages (`hiddenAt` set) return **410** with a neutral page: wordmark + «هذه الصفحة غير متاحة». No profile data.
